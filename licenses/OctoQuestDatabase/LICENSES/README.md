# License reference files

Questie-Octo is mixed-source. No single file in this directory should be read
as relicensing the entire repository. The root LICENSE scopes the MIT grant to
original Questie-Octo contributions.

This directory preserves exact or reference license texts for known upstream
components and source references. THIRD_PARTY_NOTICES.md and
Docs/SOURCE_PROVENANCE.md explain where those materials were used.

Important distinctions:

- A bundled component can carry its own upstream license.
- A reference-only project can be documented here without its code being
  distributed as part of Questie-Octo.
- A project-level license does not necessarily prove ownership or relicensing
  rights for every artwork or other third-party asset that project distributes.
- Historical snapshots can lack a license file even when current public project
  metadata identifies a license. Such cases are documented rather than guessed.
