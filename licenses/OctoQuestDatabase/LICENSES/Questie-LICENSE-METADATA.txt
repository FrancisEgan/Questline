Questie license metadata note
=============================

Audit date: 2026-08-29

The supplied Questie 5.2.3 and Questie 6.0.0 ZIP snapshots used during
Questie-Octo development do not contain a project-level Questie license file.
Their Questie/Libs/LICENSE.txt is an Ace3-family library license and is not
treated as Questie's project license.

Current public CurseForge metadata identifies the Questie project as licensed
under GNU General Public License version 3 (GPLv3). The CurseForge page for the
historical Questie v6.0.0 file also displays GPLv3 project license metadata.

References checked:
- https://www.curseforge.com/wow/addons/questie
- https://www.curseforge.com/wow/addons/questie/files/2994198

A standard GPLv3 text is preserved separately as LICENSES/GPL-3.0.txt.

This metadata note does not claim that every individual Questie-distributed
artwork is necessarily copyright-owned by Questie or was independently
relicensed by Questie. Asset provenance and exact-byte matches are recorded in
Docs/ASSET_PROVENANCE.md.
